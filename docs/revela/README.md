# REVELA

Domínio alvo: `revela.impulsionando.com.br`

## Tese

Todo talento merece a oportunidade de ser percebido, experimentado, desenvolvido e demonstrado.

O REVELA acompanha a jornada `escutar -> observar -> experimentar -> desenvolver -> provar -> conectar -> acompanhar -> reavaliar`.

## Governança

- Produto especializado do ecossistema Impulsionando, plano Full.
- Master global único: `raygs@hotmail.com`.
- Human-in-the-loop: IA recomenda; pessoas interpretam; aluno participa.
- Nenhum score único de pessoa e nenhuma sentença vocacional.
- Dados educacionais e profissionais compartilhados somente conforme finalidade e autorização aplicável.
- Metodologia versionada a partir de `RVM-1.0.0`.

## Núcleo funcional MVP

- Perfil vivo longitudinal
- Baseline e pesquisa mensal de 5-8 minutos
- Perguntas trimestrais adaptativas correlacionadas ao histórico
- Micro-observações docentes
- Triangulação: auto percepção + observação + evidência prática + tendência temporal
- Snapshots mensal/trimestral/semestral/anual
- Planos de exploração 30/60/90/180 dias
- Experiências com pré/pós/follow-up
- Oportunidades empresariais descritas por problemas e competências
- Matching explicável sem contratação automática
- Provas práticas baseline -> aprendizagem -> transferência
- Follow-up 30/90/180/365 dias
- Dashboard de impacto longitudinal

## Indicadores

Dimensões iniciais: análise, criatividade, execução, relacionamento, liderança, adaptação, tecnologia, comunicação, operações, produto, serviço, artes, habilidades manuais/técnicas, ciência e empreendedorismo.

Cada inferência relevante precisa mostrar confiança e origem das evidências. Divergências entre fontes são sinal de investigação, não erro a ser apagado.

## Automação Full Impulsionando

Jornadas N8N previstas para onboarding, consentimento, baseline, pesquisa mensal, trimestre, observação docente, comitê, experiências, oportunidades, provas e follow-ups. Templates devem ser versionados e auditáveis. Falhas precisam de retry, log e alerta operacional.
