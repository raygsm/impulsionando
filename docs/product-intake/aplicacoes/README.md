# Aplicações

Cada pasta = **tenant ou app** do ecossistema Impulsionando.

## Estrutura padrão

```text
<aplicacao>/
├── README.md
├── problemas/
├── novas-funcionalidades/
├── melhorias/
└── especifico-tenant/    ← quando o pedido é só daquele cliente
```

**Plataforma** tem ainda `modulos/<nome>/` para auth, CRM, billing, etc.
