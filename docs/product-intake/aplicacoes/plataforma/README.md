# Plataforma Impulsionando

**Escopo:** apex (`impulsionando.com.br`), `www`, `app.impulsionando.com.br` — venda, auth global, admin master, CRM core, billing.

## Onde salvar

| Tipo de pedido | Pasta |
| --- | --- |
| Bug geral | `problemas/` |
| Feature nova geral | `novas-funcionalidades/` |
| Ajuste em algo existente | `melhorias/` |
| Exceção comercial | `especifico-tenant/` (raro na plataforma) |
| **Por módulo** | `modulos/<modulo>/<categoria>/` |

## Módulos disponíveis

`auth` · `billing` · `crm` · `agenda` · `comunicacoes` · `automacoes` · `fiscal` · `integracoes` · `core-admin` · `vitrine` · `suporte` · `geral`

Exemplo: login em `app.impulsionando.com.br` → `modulos/auth/problemas/`
